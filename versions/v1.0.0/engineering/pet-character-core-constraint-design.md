## 4. 有限候选与联合约束

以下是本项目推导的离散设计，尚未编成或运行求解器。前提是 M 已为相容、连通的实际曲面网格，T 为有限三角集合，F 的单面检查不失败。

### 4.1 面覆盖和保留边

每两个共享一条可删除边的 T 中三角最多形成一个候选四边面 q。四顶点必须不同，边界简单、有向一致；双对角线折面、退化、边长比 >3.5 的候选直接排除。原接口、固定环、F 边界及其他登记保留边不参与删除。单面筛选使用最终 float32 点位。

设 `x_q ∈ {0,1}` 表示选中候选，`y_e ∈ {0,1}` 表示实际边 e 保留：

- 对每个三角 t：`Σ(q 含 t) x_q = 1`，保证每片恰好覆盖一次。
- 对可删除边 e：`y_e = 1 − Σ(q 删除 e) x_q`；其他边 `y_e = 1`。
- 固定面 F 不参与配对；保留它们的坐标和连接。

这保证的是登记底网上的完整配对。无法覆盖的三角、无候选的区域、保留边冲突均应给出编号；不得增加虚拟邻接、复制固定点或输出夹杂三角面的结果。

### 4.2 原核心与最终真实一圈

所有候选顶点位置固定后，核心 C 按原定义确定：75 mm 球内顶点加四条原导向环。设实际度数 `d_v = Σ(e 接 v) y_e`。用二进制 `p_v` 标记最终保护集合：

- `v ∈ C` 时 `p_v = 1`。
- 其余 v，对每条通向 C 的候选边 e，约束 `p_v ≥ y_e`，且 `p_v ≤ Σ(e 从 v 通向 C) y_e`；无此边则 `p_v = 0`。
- 用已知初始度数选择有限常数 `M_v = degree_M(v) + 4`，施加 `−M_v(1−p_v) ≤ d_v−4 ≤ M_v(1−p_v)`。

因此保留下来的邻边才决定一圈成员，成员度数必须为四。不能先从某个旧网格固定 P，也不能把切缝两侧的重复邻居计算两次。对 F 与新域交界也执行同一规则，避免新接入核心边后产生极点。

### 4.3 相交和支撑条带

单面合格但共同选中会发生非法相交的候选对 `(q,r)`，加入 `x_q + x_r ≤ 1`；与 F 相交的候选直接排除。共同顶点/边的合法接触按原审计口径处理。宽阶段筛选可以加速，不能因预算不够省略冲突对；冲突表不完整时拒绝求解准入。

F 已提供固定环之间的实际四边条带。肩顶与腋下仍需从**新候选连接**形成成对、不共享顶点且围成连续四边条带的候选 s，带上原语义几何检查及不复用关节环的结果。对每类条带选一个 `z_s`，并要求 `z_s ≤ x_q`（条带使用的所有 q）。被选条带上的点及最终实际邻居也施加四价条件，可用 `z_s`、`y_e` 的联合激活表达。连接方向仍须 ≥0.85。

条带候选的实际枚举尚未完成；没有对应集合，就不能把只有覆盖/四价的解称为完整肩腋通过。旧失败核心的支撑路径 ID 不直接沿用。四个环仍仅是拟用上臂导向，未获肩关节位置认证。

### 4.4 双向贴合的可编码条件

源→补片仍使用原 35,460 个源三角中心和边中点。对每个源采样 i，预计算哪些候选/固定面距它 ≤2 mm、哪些 ≤1 mm；前者要求至少选中一个，后者用二进制 `h_i` 计覆盖。为避免不同四边剖分造成遗漏，预计算采用两种对角线距离的较大值作为保守上界；最终仍执行原审计。

补片→源保持原协议：所有顶点、实际唯一边的中点、每面中心及 4×4 双线性网格。顶点计数固定，边样本由 `y_e` 激活，面中心及 16 内部样本由 `x_q` 激活；F 的相应样本作为常量。对距离 >2 mm 的必选样本立即拒绝，对可选样本禁用其边/面。双线性内部点必须实际测量，不能以原两片三角的误差替代。

在不增删顶点、一次配对只删一条内部边的前提下，令 `V,E_M,F,T` 表示实际混合网格计数，最终采样总量固定为 `N = V + E_M + 17F + 8T`。这来自原协议 `N=V+E+17Q`、`E=E_M−T/2`、`Q=F+T/2`；后一个原协议公式与两份存量报告的 24,416 / 14,416 采样数核对一致。

为表达 P95，使用一个**充分但稍保守**的计数条件：超过 1 mm 的激活样本数 ≤`floor(0.05×(N−1))`。源方向即至少 33,688/35,460 个采样满足 1 mm，全部满足 2 mm。这个条件能保证默认线性插值 P95 ≤1 mm，但不等价于原阈值的所有边界情况；不得把它导致的不可行解释为原合同不可行。[NumPy 2.4 的百分位定义](https://numpy.org/doc/2.4/reference/generated/numpy.percentile.html)。

该设计没有放宽原 1/2 mm 门槛，也没有把有限采样升级为整个连续曲面的误差证明。预计算须绑定原源、float32 输入和原审计距离口径；数值边界或不同剖分的差异必须由最终独立检查确认，不能用求解器容差豁免几何失败。
