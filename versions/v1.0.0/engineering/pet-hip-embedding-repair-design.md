# 髋裆连续曲面修复方案

> CHANGE-117，2026-10-10。依据 CHANGE-116 三份失败实物定位作者映射错误；保持获批 hip-v3、骨架、原参考场和正式门禁。本文不修改 CHANGE-115 获批设计的原字节。

根因已经定位：逐列作者规则没有保持曲面映射的连续性、周期次序和面方向。下一构造采用共享曲线的裤形曲面分块，先重建中央裆部和上腹扇区的完整连接，再作者坐标。内存预检工具已实现；目前没有符合全部门槛的新修复网格。

## 1. 实物证据与因果边界

三份实际 Blend 的连接表完全相同，最终实际两对角折面共 36 个、全四种对角组合自交共 131 对。新增内存读取器完整重放两份折面索引及全部相交记录一致，排除了保存器改变连接这一解释。组合上可定向的二流形仍可能存在几何自交或退化；连接正确不能证明空间嵌入正确，参见 [CGAL Polygon Mesh Processing](https://doc.cgal.org/latest/Polygon_mesh_processing/)。

| 已证实错误 | 具体位置和数值 | 修复要求 |
|---|---|---|
| 分叉处参数含义突变 | 左 slot24 row3→4 的实际 Y 从 37.055 变到 −27.172 mm，Z 仅下降 1.274 mm；原 raw guide 已跳 −62.130 mm，残差再增加约 −2.097 mm。右同类跳变约 −58.8 mm | 同一物理列使用连续曲线和同一原三角连接域；不能在 body/leg 间直接替换 fraction 含义 |
| 裆桥端部回折 | back 端 Y118.368→122.188 mm，front 端 −135.388→−128.580 mm；实际面147/343两种对角均折 | 桥端与外侧曲线共享端点、相容的出入方向；审完整相邻面 |
| 横向反序和扇形扭曲 | 原 26 mm 横向公式在 row1/2/3 将 slot23→24 的次序反转；同一 u 下各列 Z 不同，并非同一截面 | 明确周期相位、曲面分块及各列站位，不能只检正 X 或统一 u |
| 接口残差新造折面 | 内部27折面中24个在原 guide 层已折；229/256/284三个是在 `u * endpointResidual` 后才折。面256原 guide 双对角 cos约 .998/.998，实际第二对角约 −.00965 | 接口承接必须有明确空间域；审施加承接后的完整点表，原 guide 通过不替代最终点表 |

131 对的位置分组为桥端邻域18、至少一个面混 body/leg 查询78、其余全 body 前部覆盖35；这是排他位置分类，不将每对都强行归于唯一错误。36 折面为桥端2、全 body 后部8、全 body 前部8、混 chart15、全 leg3。

保持同一物理 X，在原 row4 截面反解真实 leg fraction，能够找到左原 triangle98360、右 triangle80030 的连续见证；相对上一站 raw Y 只差 −.685/−.520 mm。它证明该 6 cm 跳变来自作者分支规则，不能用来解释为原表面必然断裂；单修该分支并不修复整片曲面。

椭圆反事实还在髋环覆盖、有向 connector 和保护区失败；不能把零折面/零自交写成髋诊断通过。所有 AR≤3.5、固定参考切向、物理保护和贴合要求保持。

原统一横向幅值也不能靠一次改数解决：保前部邻列次序要求左 W≤6.659 mm，保证 slot25 落在真实 leg 查询区间要求 W≥17.173 mm；右相应 ≤6.665 与 ≥20.216 mm。这只是原 u/weights/formula 的有限矛盾，不能推导任意三维曲面无解。

## 3. 采用的连接方案

采用完整592原面工作域。原许可 source 的真实边/四边面只提供拓扑父身份和有向周期次序；它来自 `Stylized Female`，raw 来自 Sprout `char1`，不是同一对象或三角索引域。两者必须另外建立物理对应，不能直接把 source ID 写成 raw triangle ID。

源域已经精确拆成七块，全部原 face/edge/vertex IDs 及有序边界保存在归档中。采用它们是为了控制共享曲线与分叉对应；已有零折/零自交反事实说明，不能据源列分类断言旧512作者图必须重建：

| 源曲面块 | 原面数 | 已实核结构 |
|---|---:|---|
| 左、右外侧 | 168＋168 | 各12×14规则 quad disk |
| 前跨裆 | 24 | 8×3规则 quad disk |
| 后跨裆 | 56 | 14×4规则 quad disk |
| 前上腹扇区 | 72 | 单边界disk，42边，两个5价点 |
| 中央裆部 | 38 | 单边界disk，28边，两个3价和两个5价点 |
| 后上腹扇区 | 66 | 单边界disk，48边，两个5价点 |

每侧28条源列中15条通向上界，9条跨至另一腿，4条在真实极点终止。因此必须按真实块边界接合，不能把全部28列假设为腿→腰。

### 3.1 先使中央裆部成为规则网格

中央域当前两条腿接口各3边；前共享曲线8边，后共享曲线14边。保持左右腿接口点/边/绕序，将**同一条前共享曲线重采样为14段**，并同步整个前跨裆块及其与前上腹扇区的另一条共享曲线。

中央可规划为14×3规则 quad 网格，前跨裆同步为14×3；中央原两个3价和两个5价点不再继承。这是明确的内部计数修复，不是单独拆旧面或给固定腿接口插点。后跨裆14×4与两外侧12×14父表保留作布局依据，最终连接仍需完整重新作者、校验。

必须首先冻结的中央曲线为原有向 `6997→9735` 与 `10764→8026`。每条共享曲线在目标 raw 上只有一份身份、端点、方向和点表；相邻块引用同一 key，不分别重查 body/leg 或镜像重算。

### 3.2 在稳定上腹处理扇区与极点

两个上腹扇区具有六条真实边界段，不能用一个中心六价点加盲目的 Coons 填充。需提供明确的新连接表，将必要极点留在稳定上腹，并在其与真实接环/裆部之间保留实际四价邻接缓冲。

一份有限计数构造已推导：每个上腹fan以upper6弧中点至lower14弧中点的8边路径拆成左右五边disk；半块边数[3,12,2,7,8]，五个规则quadsector的整数spokes为[2,7,1,5,1]，各33quad。全部正整数只证明该有限连接算法能列出网格，不认证极点一圈与四环。该完整索引表尚未生成；两条spoke仅1边，极点会直接邻接共享曲线，保护必须按实际新坐标独立检查。未采用为施工表。中央与前跨裆计数变化还将前上腹边界42改为48；592仍是原删除足迹，不硬保旧512新面数。

旧前六价点858本身在保护并集外，但邻点519/687进入左 groin 固定盒，真实图距为1，所以失败。必要条件是极点及全部直邻都在完整并集之外；新低裆桥可能改变直邻归属，必须重查。保持原 core、原 raw 区域、固定盒及真实一圈，不能只抬极点、改盒或豁免边界。

源身份与坐标冻结分开：336继承面所用392坐标及固定下接口保持；上腹49/44/52共120个旧作者点不是这392点，其 target 坐标可在新 recipe 中重新作者，source IDs/谱系保持。上界40点的身份、边数和绕序保持，新目标坐标在构造前独立冻结。旧80点表、旧模型和获批设计保持原字节。面38的AR3.50171075来自旧80作者点，不能误当必须保留的源质量下界。

## 4. 目标曲线与接口承接

56个固定接口方向的原 raw 半平面观测已实核：每方向唯一 body 连通截段、接口轴向站位唯一命中、有限折线轴向单值，离骨轴至少35.423 mm；原 triangle/barycentric 世界回构 exact，坐标变换误差≤1.11×10⁻¹⁶ m。左右28方向各自有严格单向周期次序。

这些观测可以作为新物理对应的输入，却不能直接采用恒角度轴站位的四环构造：最窄共同上游轴向域约5.807 mm；某些 guide 与冻结切向的 absdot最低约.7323，低于保持的.85。其上游真实弧长最窄18.661 mm，也不单独证明 AR 能过。两侧独立 seam 端点差最大.433 mm，共享曲线须统一作者，不能直接镜像拼接。

沿原 raw face 内骨轴梯度、经原三角共边推进的连续 guide 已完成一次完整56列观测。作者方向只由原face平面与不变骨轴产生；固定顶点法线/bary切向另用于测量，最差有向dot .990906，未反求法线或以成功connector拟合参考场。611段和555次共边转移的原triangle/bary独立回构通过，0/7/14 mm三站每侧28列严格保持原周期方向。这说明原分叉查询突变可以被连续原表面路径替代，但有限曲线观察不认证整片网格。

唯一固定三段7 mm、总21 mm同侧环带假设在施工前被否决：54列满21 mm，左/右slot27分别在20.402857/20.634464 mm到真实X=0，因此缺两个21 mm站。222个可用站绑定通过不能冒充完整224点表。此次没有缩短长度、延长曲线、跨中线补点、扫描fade，未产生224V/168Q点表、BMesh或Blend。

联合分叉采用**一份真实共享裆缝**。复用既有X=0原截面，原观察Z[.09,.355]内有一条193原段开式路径，前上端→最低裆点triangle89136→后上端。两slot27终点落在同一前下部弧，但分别在共同弧长q=.259434774/.261204318 m，间隔1.769543 mm；不能平均、镜像或默认合并它们。以共同原triangle曲线身份/q站位和共享node keys划分邻接面块；整条闭合轮廓有两个方向路径，此处唯一性只针对该既有有限开式路径。

下一坐标作者先确定每块在这个共同裆缝上的端点和有序区间，冻结共享曲线，随后填充各块与明确接口过渡域。取消两条独立leg chart跨裆底继续挤占的构造假设。该新域连接仍须给出真实四环与双groin支撑；21 mm失败不证明任何四环或裤形曲面都无解。施工曲线入口为归档 `cause-reference/ordered-seam-v2.json`；初始观察的有向边标签缺口和修正控制失败均原样保留，不能用旧标签驱动新作者。

接口使用同一已冻结端点对应，避免旧极值槽10在相同端点处再次换 guide而引入额外约5.98/8.22 mm。承接只作用于明确的边界曲面块，完整审其后的邻列次序、面方向及覆盖；取消全列无约束的 `u * endpointResidual`。原接口与 raw 最大偏差约15.78/15.33 mm并非已证实相位错绑，仍需实际 collar 和贴合验证。

## 5. 构造与验收顺序

1. 完成七块共享曲线表、两个上腹扇区替换表、中央14×3与前跨裆14×3的完整目标连接；所有边界方向、raw原三角绑定、作者坐标和坐标所有权先冻结。
2. 检查一组件、原三接口与336继承面、χ=-1、四环各28点及真实连续quadstrip、双 groin 路径、极点保护缓冲。共享 key保证边界位置一致，但不自动保证没有翻面。
3. 运行新增内存预检：Blender实际float32存储、两对角折面、全四对角组合自交、AR≤3.5、T点、退化/重复/内部非流形；再运行不变 v3 对完整点表的预检。形体与物理对应独立检查。失败保留表和确切原因，停止依赖的模型保存。
4. 只有完整构造前提通过，才保存同一冻结表的隔离 Blend；独立重读实际点/面/属性，复查固定样本贴合及原尺寸视图。实际保存身份和几何验证都不可用作者意图代替。
5. 全部诊断通过仍不提升全身五接口/S0/闭合身份/rig。原骨pivot/head/tail/roll、许可/资源、其他关节及历史失败保持。

预检工具为 `tools/pet-model/rig_v2_hip_embedding_preflight.py`，20项输入边界控制和9项真实Blender几何控制通过。包括合法共边接触、越共边相交、两面各自不折但彼此相交、裆桥实际折面、残差新造实际折面及T点。所有权策略须明确区分可作者点和冻结继承点，任何继承面坐标解冻都被拒绝。
