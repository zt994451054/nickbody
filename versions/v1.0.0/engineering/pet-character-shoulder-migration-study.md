## 2. 已测清的几何条件

以上均为原三角表面与平面的真实交线，并分别排除了同一平面切出的头/躯干/腿部曲线。
每站恰有一个符合 `X > 0.04 m、0.30 < Z < 0.48 m` 的完整轮廓。
有序 32 点导向保存在 `arm-sections/section-guides-32.json`：从最前方交线点开始，沿截面轴正绕序、等弧长取点。
这些点仍是**导向曲线，不是已构造网格上的结构环**，四站也尚未由生产关节区域审计认定为 shoulder rings。

四环间隔 10 mm，平均周向边约 10.8–11.6 mm，因此先选 32 点有实测尺寸依据。
截面长短轴比约 1.45，向远端略增粗；圆截面及解析样例的渐细假设都不适用。
更近肩根的 `s=0.08/0.10/0.12/0.14 m` 均没有独立手臂闭环，实际交线仍延伸到躯干。
原始失败切片完整保留，未把躯干轮廓裁成“肩环”。下一步必须制作肩上盖和腋下的连续过渡。

参考窗口固定为 `X=[0.035,0.225]、Y=[-0.13,0.13]、Z=[0.32,0.47] m`，
以三角形全部三点均在盒内选取 **8,545 面 / 4,653 个导入顶点**，并保存 564 个真实邻点一圈保护面。
坐标相同的 UV 接缝只在分析索引中合并，得到 4,408 个物理点、Euler 0、两条 164 / 107 点简单边界。
源文件和 UV 没有焊接或编辑。边界总边数 271 为奇数，不能把原边界全部锁死再声称能纯四边封接；

## 4. CHANGE-066 制作任务与预算（已执行，结果见 §6）

**目标：一份贴近上述真实肩腋参考的无骨架四边补片及独立审计。**
新方法先在真实源三角面上建立明确、可检查的局部曲面坐标，再依据实测导向直接布点。
它不调用旧 builder，不把解析圆柱/分支管生成后整体 shrinkwrap 回身份，也不沿 B1 原三角点位换边。

执行顺序固定如下：

1. **源曲面坐标与边界。** 在只读窗口及已保存一圈内，标出前胸、后背、肩上盖和腋底。
   采用带 source face ID 与重心坐标的局部二维参数域；先验证一一对应、UV 三角有向面积同号，
   禁止跨图跳到头、躯干另一侧或其他壳。重新声明隔离补片近端有序边界，拟用 64 点；
   远端固定使用 s=0.20 的 32 点导向。源窗口的 164/107 点边界不直接照搬成新 mesh 边界。
   边界实际坐标、角点与 source 对应须在构造前一次写入 manifest；无法在窗口内闭合就停止此布局。
2. **显式面连接与布点。** 四个拟用关节环各 32 点，以 `(R[k,i], R[k,i+1], R[k+1,i+1], R[k+1,i])`
   连接；向近端的密度过渡、肩上盖和腋下各两条不相交路线必须列出真实 face/edge/vertex ID。
   64→32 密度转换及所有极点只放在胸背稳定面，不能侵入关节、支撑路线及各自真实一圈。
   每个新点通过已绑定参数域取 source 对应，允许内部点重排；禁止全局最近面贴回或重置边界。
   需要实际验证过渡连接和三维点位；本文件不把环带公式当作已完成的全部布局。
3. **静态验证与有界修正。** 首版先保存，再做真实 mesh 审计；只允许一次同域修正，
   参数域、边界、点数和验收标准固定。曲面最近距离仅用于独立量测，不能作为跨壳移动操作。
   修正后的 float32 几何重新审计；若机器和原尺寸观感都通过，才讨论扩大到完整身体。

下一次局部制作总主动工作上限 **90 分钟**，包含布局、代码、测试、审计、原图和归档；
最多 **一份首版 + 一次同域修正**。源参数域及完整连接设计须在前 30 分钟内成立；不成立则按失败布局结项，
不接着换边界或另开参数搜索。若需要局部求解，两次共用最多 200 迭代 / 300 秒；不用求解也照常记账。
最多两次实际 Blender 静态审计，成功时可另做一次精确重放验证；重放不得优化或产生新版本。
这是独立真实肩部研究的预算，不继承或重开旧路线额度。CHANGE-066 量测阶段未消耗，CHANGE-067 的实际消耗见 §6。
