# 髋部修复设计：枢轴、表面腿根与变形过渡

> CHANGE-115，2026-10-10。方案评审稿，未激活机器合同。现有 v2 合同与骨架不改；完整角色仍阻塞。结论由实际骨架、原源邻接与数学运动量测共同支持，尚未获得修复后的网格。

## 1. 设计结论

推荐保留髋枢轴和 UpperLeg 骨长轴，把皮肤腿根的测量参考与骨骼旋转参考分开；以完整下腹—臀部—双腿分叉为重布单位，重建宽度合理的接环和裆部双支撑，再按原阶段顺序验证变形。不能通过下移髋点、重标跨膝旧圈、缩小保护区或统一加密解决当前问题。

这是可执行的施工路线，尚不是已完成的替换连接表或合格模型。在同一有界施工批次内先作者完整 quad 表、全部目标点位和保护区，再输出供审查的实物；缺任一项就不输出“修复候选”，不另开前提研究批次。

## 3. 静态规则为什么需要单独修订

半径/轴向窗口/环法向/方向指标最初来自 App `135cc9b` 的通用 DCC 筛查；`56477f8` 将四环、连续条带等纳入机器合同。首版控制主要是肘区圆柱及三角/极点反例，没有真实髋完整动作校准；旧髋 smoke 只有一组双侧本地 X 小姿势（左 +20°、右 −20°），明确未批准蒙皮、变形或动画。不能把这些阈值称为自然髋变形的充分条件，也不能因为缺少校准就自动放宽。

仅把环测量中心换成表面中心，同一有限四行 56 点构造的环几何可以通过，但子面最大 AR 仍为 8.729/8.731，旧冻结观察轴纵向最小对齐仍约 0.464/0.461（正式骨长轴约 0.457/0.453，两种轴差约 0.497°）。原始 28 面局部插点还会产生每侧 56 个边界 T 点。**这份诊断构造不采用。** 更多纵向行不会改变原 connector 方向，也不能代替分叉重布。

建议的版本提案仅涉及 hip 接环语义：

1. `jointPivotFrame` 继续绑定原骨架；`skinAttachmentFrame` 独立绑定施工前冻结的参考表面/接环锚点。审批后才可更新机器合同、审计器和 Skill 同一版本/哈希。
2. 四环数量、同侧等点数、真实一一对应 quad strip、每侧两条 groin 支撑、无极点缓冲以及 AR≤3.5 保持；严格翻折/自交/非流形/退化/重复/T 点仍必须为零。现有其他关节与 canonical 接口规则保持。
3. hip 环窗口改为在固定表面参考框架内测量，沿用原 45/100 mm、coverage≥0.95、normal≥0.9、edge-dot P95≤0.42 等数值作初始静态筛查；观察轴暂沿用现有审计器的冻结轴，并与骨架精确 Y 轴分开记录。参考框架来自冻结参考，且须补齐 raw REST 接环锚点验证；不允许从待测候选反求中心使其通过。
4. hip connector 的拟议方向改为冻结参考表面的纵向切向场。按骨盆→腿接口的环序定义正向，将原绝对 dot 改为有向 dot≥0.85，数值保持但增加禁止回走的约束。切向为 `normalize(b-(b·n)n)`，n 来自构造前固定的参考面/三角锚点；近零投影、方向不连续或缺失锚点直接失败。候选点必须绑定该固定场，不能使用候选自己的 normal/connector 当参照。原全局骨轴结果继续输出并保留历史失败。
5. 这是待审批、待实现并待校准的规则提案；新的参考方向也不保证现有 connector 通过。不得把提案诊断输出送入正式 decision、S0 或 rig 流程。

固定原面切向诊断验证了这一点：28 个父面上投影后的最小 dot 仍为左 0.641334、右 0.641355，小于保持的 0.85；最差原面 `7088/9795` 位于内裆。表面倾斜解释部分全局方向误差，但真实布局也需要改变。该有限原面诊断的 n 不冒充已冻结 raw REST 生产切向场。

## 4. 具体施工单元与顺序

基础分叉域由原环 `49 / 1 / 97` 围成，含 536 原 quad、583 点。再纳入左右第一接环带各 28 原 quad，工作域共 **592 原 quad、639 点、1232 边，χ=-1**；上界仍为 40 点 cycle49，下界改为 28 点 cycle5/101。原 cycle1/97 留作皮肤形状参考，作为内部布线可修改。扩域完整 928 原 quad 中域外 336 个腿部 quad 保留。最终外界面只接原 28 点接口，不能插点后留下 T 点。每侧采用 28 点环可保持接口点数；此前四行 56 点诊断不是本次布线模板。

按以下顺序直接作者整体 quad 布线，不调用已关闭的调和模板、旧 refinement、nearest/shrinkwrap 或优化器路线：

1. 冻结原输入、592 面删除足迹、上下三个接口的点/边/绕序及 raw REST 表面锚点。源 cut49 新上腹点需独立作者 Sprout 目标坐标；原 source 坐标不能直接当目标坐标。
2. 先划出左右前→内侧低裆→后的两条真实支撑边路与连续 quad 面带。旧左面 `[7118,9338,8654,9368,8720]`、右 `[9825,12045,11361,12075,11427]` 仅用于定位。绕路不得借用跨膝环替代裆部支撑。
3. 接环初始选择每侧四个 28 点闭环，与保留腿接口匹配；行距和横向分配按实际曲率和面宽重新作者，不能直接把旧窄带等分。四环只表示静态采样布局，不代表整个变形过渡仅有三排面。
4. 在接环、双支撑及全部保护区外布置分叉所需极点。原路径附近 `8677/9336`、`11360/12023` 必须从实际危险邻域迁出；旧单边 flip 的新增三/五价点失败方案不复用。不能要求整个分叉全四价，也不能只靠上移截口宣称极点已迁走。
5. 为所有替换点保存目标坐标、冻结参考 triangle+barycentric 或明确 cage 作者来源；保存全部新 quad 索引、source 删除足迹及边界拼接。替换面不再假称原 quad 原样继承。
6. 保护区取原髋几何核心与新接环/裆部区域的并集。接环/裆部物理参考区域须在候选作者前冻结 triangle/区域身份；之后只映射到最终实际网格并扩一圈，不随候选收窄、改名或免除边界极点。cage 来源的点也须绑定固定参考场和区域。不能用原 source 图距代替新邻接证明；稳定极点区必须实际位于该并集及一圈之外。此 mask 先约束拓扑，生产阶段再按 Rig §7.2 定义和审核权重过渡 mask。
7. 保存 Blend 后用独立读取器验证实际点/面/属性、三个接口及 336 保留面；运行严格几何与固定参考形体检查并看原尺寸视图。只读标注、曲线和规划 JSON 不计网格交付。

实际新 quad 表、上腹目标点位和稳定极点坐标尚未作者。这三项是下一次施工必须完成的工作，而非本轮已经通过的前提。

## 5. 变形要求及验收顺序

刚体数学探针使用冻结骨架本地轴，不建骨、不写权重或动作。90° 本地 X 旋转下，左右上腿根平均刚体位移需求约 152.9 mm、下腿根约 168.4 mm，最大约 198.4 mm；旧 pivot 附近几何核心平均只有约 56 mm。点到骨枢轴的杠杆不同，单在枢轴附近审核圈不能覆盖真正承受运动过渡的皮肤。

这些数值是单个骨变换的运动需求，**不是实际蒙皮后的位移或可接受误差**。对于假想两变换混合，`x'=x+w(x)(R-I)(x-P)` 的导数含位移差与权重梯度耦合项；窄过渡、大运动差以及斜瘦面可能共同导致压折，但该推导不能选定权重或证明当前拓扑必定失败。区分几何、骨变换与权重的依据见 [SIGGRAPH Skinning 课程](https://www.skinning.org/direct-methods.pdf)。

执行顺序：

| 阶段 | 必须交付 | 失败处理 |
|---|---|---|
| 合同/路线审批 | 本文件及精确 SHA 提案；固定表面框架和可读变更范围 | 不激活机器规则、不进入下一施工批次 |
| 一次有界局部重布 | 全部新 quad、点位、真实 masks、双支撑及完整拼接 | 任一前提缺失不生成模型；首份+最多两次内部修订共用三小时，不滚动续期 |
| 局部独立验收 | AR≤3.5；严格几何零；四环/支撑/保护区；原尺寸形体和双向参考误差 | 只输出具体失败，不作为正式 S0 或形体批准 |
| 全身开放五接口与闭合身份 | 全身 S0、身份量测、专用闭合评估器和用户静态审批 | 当前 592 面局部不能替代任何一项 |

不把有限采样 P95 当连续表面证书，也不新增“约11mm即可接受”的形体门槛。后续局部原尺寸检查及原项目形体/身份底线仍适用；mask 和合格环不能免除真实变形认证。

新批次的三小时总预算统一覆盖输入落实、规则实现/控制、完整连接与点位作者、首份实物及最多两次内部修订、独立验收、归档和双仓推送；开工时记录新 UTC 起点、检查点及总截止，不结转此前已结项额度。保留的336旧面本轮实测没有AR>3.5面，不能据此推断新592或整个928面通过。
