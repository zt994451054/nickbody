## 6. 针对映射缺口的研究与下一项

已转向“不同体型表面之间建立对应”，不是继续搜索一般重拓扑案例：

- [Kraevoy / Sheffer 2004](https://www.cs.ubc.ca/~vlady/cross/cross.htm)：借鉴成对特征和相容分区；作者 ZIP 是模型示例，未核实算法实现入口。
- [Schreiner 等 2004](https://hhoppe.com/proj/intersurf/)：直接优化连续表面映射；未找到已核实可直接使用的该论文实现。
- [Surface Maps 2023 官方代码](https://github.com/patr-schm/surface-maps-via-adaptive-triangulations)：有实现，基于球面嵌入，Linux 测试；本机及五开口/固定接口能力未确认。
- [Implicit Minimal Surfaces 2026 官方代码](https://github.com/RobinMagnet/implicit-minimal-surfaces)：有 Python 实现，但明确要求闭合 genus-0 三角网，landmarks 是软约束；不能直接作为五开口输入和硬固定接口的方案。

详细能力筛选见档案 `mapping-research.md`。以上均为资料依据，未安装、运行或产生本项目映射。

**下一项交付改为具体的对应数据和方法准入表**：由 AI 在现有源/目标数据上列出肩顶、腋底、胸背、髋裆及五接口的成对点/曲线身份、方向和缺失项；从上述有实现的方法中核实一种的边界表达及运行前提。30 分钟检查点、60 分钟总预算、新网格上限 0。若需要封口、软化固定点或回到已关闭投影方法，明确记录其影响，不能直接执行；若没有完整可执行对应，不追加样件或微调。

这是后续适配方法的一次输入/能力核查，不承诺其必然成功。映射通过后，仍需完成分支支撑和五接口布局，再按原准入条件考虑唯一肩腋样件；下游 UV、身份、骨架与动作按统一清单依赖执行。

### 8.3 目标拓扑与方法能力

本轮从完整原始小草数组检查得到：精确同坐标分析后 **88,235 点、264,699 边、176,466 三角面，单组件、Euler 2、零边界**；重复面、反向共边、非流形边和非流形顶点均为 0。这满足闭合 genus-0 的组合条件，不代表自交/几何或生产身份通过。旧完整人体审计也记录闭合 Euler 2；当前 5,626 面身体视图则有 136 条边界边，Euler −3。

已核查 [Surface Maps 作者实现](https://github.com/patr-schm/surface-maps-via-adaptive-triangulations)固定提交的 18 份文件：

- 五开口输入在入口直接被拒绝；**完整闭合参考仍可作为研究方向**，不必为了该参考用途先制造封口。
- 有硬特征点开关，但默认先用软约束对齐，再冻结当前球面位置；这是源码级事实，尚无本项目执行证据，不能推成正式坐标逐位保持。
- 输入特征是网格顶点 ID；当前正式接口不是原始小草表面边界。绑定的旧测量中，五接口到原始参考的最大距离分别为颈 45.249、左右腕 33.404/33.520、左右踝 20.655/18.679 mm。本轮未重测，也不将不同制作阶段的差异判为身份失败。
- 入口会居中及面积归一化，输出公共三角网并可改连接；本机 CMake/图形依赖入口未就绪。没有安装、编译、运行或产生映射。

具体代码行、默认阶段、归一化与本机限制见档案 `mapping-research.md`、`mapping-capability.json`。结论是保留其**闭合参考配准**价值，拒绝把它当作现成的正式五接口构造方法。
