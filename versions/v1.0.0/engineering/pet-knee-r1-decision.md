## 1. 本次方案与拒绝原因

本次只允许一个主要变化：从 CHANGE-033 原源出发，重新划分必须可动的权重点与保持原值的保护点。
完整接触清单、原支持、原几何/UV/rest/动作、掌指/右侧冻结、位移盒、折角容差和实际验收均保持。

可实施的保守划分为：原膝区 1,039 点，加上全部目标接触和超限膝折角的可编辑角点。
集合并集为 1,750 点 / 4,713 独立变量；其余 439 个原可编辑点 / 1,194 变量固定在源值。
必须继续使用原 2,189 点范围的完整检查集合，不能因缩减变量而删除接触、折角或面积检查。
精确 ID 和独立变量列完整保存在 `partition-screen.json`。

这份划分没有消除已知的实际求值误差问题。保住接触自由度时，关键误差点仍必须可动；
把误差点全部固定时，目标穿插不能消除。源基准预测也在已有 K3 数据上出现实证误放行。
**本次未收敛出同时处理这些条件的完整实现方案，因此不允许直接进入 R2。**

末端 Blender 验收可以拦下错误候选，但不能代替求解过程中的误差处理方法。
继续开发新的误差界、逐步实际求值驱动或更精细变形预测，已是另一项主要方案；
本轮不把它们作为“再补一个诊断”接回原路线。这个判断不等于它们在技术上不可能实现。

## 2. 可动点与保护点的具体核查

完整源恢复清单为 1,534 个姿态—面对：15°/60°/转身/跳跃分别 0/30/476/1,028。
涉及 1,141 个面、1,058 个规范顶点，其中 849 点位于原可编辑区。
旧膝折角超限为 0/142/136/121 行，角点与接触角点联合后有 1,067 个可编辑点。
上述均为现有源的范围数据，没有新候选，也没有修复前后改善。

| 划分检查 | 结果 | 能说明什么 |
|---|---|---|
| 全部 282 个失败保护点保持原值 | 310 个严格穿越见证，涉及 172 个目标姿态—面对的固定穿越特征 | 即使离开旧 K2 小邻域，这个具体固定方案仍不能消除这些穿插 |

| 上述保守划分对 169 行实际失败的影响 | 22 行的全部角点可保持原值；147 行仍涉及可动点 | 22 行不是新模型验收通过；其余仍须处理实际误差及邻接约束 |

172 对的所有 310 个见证已分别用历史源缓存与 K6 实际源坐标执行原有精确有理数穿越检查，
全部成立。第一次核查曾错误要求两类历史采集坐标逐位相等，断言失败；
确认它们最大相差 1.4901161193847656e-7 后，改为分别核对原有精确几何判据，没有修改数据或容差。
K3 的原源坐标与 K6 旧路径源坐标逐位一致。这不是源文件哈希漂移，也未新增采样。

## 3. 关键八点不能全部固定

规范顶点：27619、27765、27882、27973、27994、28174、28256、28937。
源顶点：6518、6680、6818、6916、6937、7136、7228、7990。
它们对应原 Spine01、L_Clavicle、L_UpperarmTwist01/02 支持的 24 个独立变量，
不是一组可从完整恢复目标中排除的无关点。

| 姿态 | 把八点全部固定后不能消除的目标面对 |
|---|---|
| 转身 | 55261/55746、55261/56511 |
| 跳跃 | 55261/55746、55261/56511、55511/56511、55624/56511 |

上述六个姿态—面对有 12 个已复核的严格穿越见证。
枚举八点全部 256 种可动/固定组合，其中 225 种没有固定住所查穿越；
即使取这些组合中最有利的一种，也至少保留 2 个可动点、3 条涉及可动点的已知误差敏感折角检查。
例如仅允许 28256、28937 可动，仍涉及跳跃 55261/55511、55006/55262 和转身 55745/56511。

这里证明的是：**单靠固定源点，不能同时固定全部敏感折角并保留所查接触的恢复自由度。**
没有证明每个可动组合必然数值失败，没有穷举权重，也没有证明六对接触的共同解不存在。

## 4. 换回源基准预测也没有补上缺口

用已有数据核查：

`预测 K3 坐标 = 已测原源坐标 + 原坐标雅可比 ×（已有 K3 独立值 − 原源独立值）`

未构造或应用任何新权重。采用已有 Blender 配套 Python 3.11.9 / NumPy 1.24.3，
复用原折角函数和 1e-6 容差。按相同实际源角度计算上限后：

- 12 个诊断记录中，预测失败数为 0，实际有 7 条失败记录，对应 **6 个不同的姿态—面对**。
- 最大折角预测误差为 1.7519945842403573e-4 弧度，约为既有容差的 175 倍。
- 最大坐标预测误差为 4.5062416770269564e-8 源坐标单位。

这里所有记录统一使用实际折角判据；旧 `protected/measured` 名称只作诊断 ID，
不是对 K5 混合约束族重新解释。重复记录没有加总成新的几何问题。
该结果否定“只换源基准就能消除已有误差”的说法，不是未测权重的误差上界。
