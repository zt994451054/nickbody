## 1. 为什么选择这个方向

骨位、rest 姿态和表面连接都可能影响压缩变形，现有证据支持的程度不同：

| 方案 | 直接证据 | 决定 |
|---|---|---|
| 调整膝骨中心或 rest | CHANGE-034 已做单姿势虚拟中心后移 0.04：所查左腿相交从 30 降为 0，但相邻折叠仍在；前移变为 208。原左腿选面未单独序列化，数字不是当前完整门禁。当前骨链端点连续性也没有给出中心/轴错误的证据 | 本次不选；没有排除其他骨位设计的可能性，但没有支持下一次具体移动量的依据 |
| 定向重建局部面流 | 已定位的肩臂九面在 rest 就有细长三角形，跳跃时局部面积进一步压缩；同一小簇同时参与目标穿插与误差敏感折角。膝部也有明显压缩及折回，原尺寸图可见不同高度表面挤在同一折线上。已能从原连接定义完整目标的施工包络 | 优先做一次真实施工验证；验证对象是新的连接和相应权重，不能靠更换求解器宣称方案已变 |
| 更换整份源资产、全局重网格或重做骨架 | 尚未验证本次明确包络内的定向施工；会扩大身份、UV、绑定和动作重做范围 | 当前不选；未调用付费生成或复活已停止的全局/参数化重建路线 |

选择依据是局部几何及完整目标覆盖，不是“三角面多，所以必然有问题”。
全源规范网格的 120,000 条边均有两个入射面；本轮没有发现需要用全局焊接补洞来处理的开放边。
这不证明全源的语义连接或几何符合正式 S0。

骨链只读量测：L_Thigh→L_Calf 端点差约 2.729e-5，股骨段长约 0.09511，
两段方向在 rest 相差约 16.46°。L_Upperarm→L_Forearm 端点差约 2.441e-5，
两段方向相差约 16.99°。单位沿用冻结源坐标，不能换称毫米。
这些数值不等于关节中心位于体积内或局部弯曲轴正确；本轮没有用最近顶点距离作此推断。

## 5. 下一次施工的完整交付与验收

下一阶段直接做带实际静态网格的施工验证，**只交计划或工具、没有网格，按失败结算**。
施工可使用 Blender 4.3.2 的直接 BMesh 编辑，但必须如实记录算法/建模过程，
不能把程序布局冒称手工制作。禁止全局 remesh、以最终 shrinkwrap 代替结构制作或复活已关闭方法。

静态施工先交付：源面→新面的完整对应、七边界不变量、关节连续环/压缩侧与伸展侧布线、
接缝与权重转移规则、同镜头静态图及独立几何审计。
施工前在新登记中冻结与新拓扑对应的判据；不能按输出结果改阈值：

- 区域外及固定边界保持；原右侧/掌指点、源资产和历史文件不变。
- 新区无退化、翻面、重复面、内部非流形或新增静态自交。
  关节核心和相邻环的极点、连续 quad strip、纵向方向及面比例按现有权威定义检查；
  全部必要声明必须能从真实 connectivity 验证，不能仅填环点标签。
- rest 的双向表面偏差、局部轮廓、腰部既有造型和接缝逐项比较并审核；
  不能只检查新顶点到旧表面的距离，就声称整个新表面一致。
- 同一套新权重执行 0°、15°、60°、转身、跳跃的实际求值：
  全部 1,534 对目标必须通过源区域对应重新检查；
  重新扫描新表面与全源上下文的潜在新增接触，不能沿用旧面对作唯一候选集合。
- 原受保护区域保留不劣于源的标准，原 1e-6 折角容差不放宽。
  新面的面积/翻折以其自己的 rest 及实际几何计算；旧面与新面的角度不能按数组序号硬配。
  无法建立完整对应或有未定义验收项，静态阶段即拒绝，不带着缺口进入动作阶段。
- 原尺寸视觉仍必须通过：膝部无残留台阶/深折，肩臂无新沟槽/穿插，
  腰部改善保持。不能以平均改善、数值更稳定或几条接触消失代替通过。
- 四姿态全部通过后，冻结网格和权重，再验证未拟合角度、目标邻帧、
  0–60° 逐度和原五动作的既定 305 帧，并做隔离文件往返。

静态报告只对应 vendor trial，不送 formal normalizer，不写 S0 通过或允许生产绑骨。
