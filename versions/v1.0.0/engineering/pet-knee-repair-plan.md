# Sprout 膝部修复计划 — CHANGE-037

日期：2026-09-10（Asia/Singapore）。负责人：@winston（AI 执行）。
状态：计划已制定，实施未开始。本次用户要求先制定计划，因此本轮只提交文档。

## 1. 本次要解决什么

先让左膝在小角度到大角度弯曲时保持连续、自然的表面：
15° 不新增下缘细褶，30–60° 减轻已有横向折线并解决内侧凹折，
中间角度没有突变；同时保留腰部既有改善。

本计划先完成左膝局部验证，再扩到右侧、原动作和模型交付可行性。
局部通过只能记为 vendor capability trial 的区域结果，
不等于全身、生产网格、固定骨架或正式资源通过。

## 3. 执行阶段与交付物

| 阶段 | 具体工作 | 必须交付 | 进入下一阶段的条件 |
|---|---|---|---|
| P1 定位原因 | 从 19 面样本沿实际表面邻接检查整段下缘及内侧连接，比较同一面在源姿势、上轮和本轮的变化；检查目标位移、边界方向、权重及面挤压 | 一张标明位置的局部图、静止/弯曲对应面片、证据支持的主假设和仍未排除项 | 能说明“哪一段、何时出问题、准备只改什么”；原因仍不清楚则补一次定向诊断，不盲改 |
| P2 验证局部形状 | 先制作可控的 15° 局部目标，参考源姿势较平顺的下缘；同时用 60° 检查是否保住大角度改善。优先保持现有连接关系，按 P1 证据选择目标形状或支持区作为主要改动 | 每版 0/15/60° 同镜头三组对照、修改点/边界清单及撤回条件 | 小角度不再新增细褶，大角度不退化；单纯“坐标变了”不算增益 |
| P3 左侧连续性与实现可行性 | 将有效局部目标变成可复现的随姿势变化方案；补中间角度、侧面和内部连接视角；检查该方案能否在既定 macOS 14 路径表达 | 角度扫描、边界/相交诊断、实际实现方式及未解决限制 | 左膝局部标准全部满足，且不是只能保存在单姿势 Blend 中的结果 |
| P4 右侧和原动作回归 | 在左侧稳定后独立处理右侧，检查 idle/walk/run/jump/turn 的两腿、腰髋和原有改善区域 | 双侧对照、每段动作的失败帧或完整局部回归记录 | 两侧和动作局部检查均通过；发现退化则回到相应局部，不宣布全身成功 |
| 条件分支 S 结构性修整 | P1 或 P2/P3 的证据指向基础结构问题时，选择权重、骨位或局部布线中的一个主要原因，先做最小局部验证 | 选择理由、与历史失败方法的实质区别、隔离副本及同标准对照 | 必须通过同一套大小角度与连续性检查；不能降低标准换取“成功” |

P1 先利用现有姿势数组、原图和审计器；只有缺失信息才新增定向检查。
P2 不再强制沿用旧 Hermite 目标。15° 原本较好的表面应尽量保留，
但也不能简单关闭低角度补偿后就结束，必须检查补偿开始生效附近的过渡。

若 P1 表明问题跨越当前边界，需要先标出新的局部支持范围并冻结远端，
不能一边任意扩大范围，一边调整权重、骨位和算法。
每版记录一个主要假设；改变第二个因素时另存版本及其对照，避免无法归因。

P3 的可实现性先对照已有导出/往返报告。身体完整性不能依赖 macOS 15+
才有的可选 corrective API，也不能假定导出器自动烘焙任意顶点修正。
若形状只能靠无法可靠交付的补偿实现，则只留作形状参考，转入基础结构方案。
必要的导出验证使用隔离测试资产；生产 Gate 和正式资源切换仍执行原合同。
进入原动作前核实骨骼局部轴与真实旋转，不能把当前 world-Y 单轴探针角度直接
套到组合动作。动作超出已测角度时补测实际范围，不能外推“已通过”。

## 4. 验收方式

两条对照必须同时看：相对源姿势有没有新增问题，以及相对上轮有没有真正改善。
首次定位和每版筛查保留 1000×1000、yaw 70/-110° 的同镜头对照；
P3 增加能看清膝内侧和轮廓的视角，固定相机后再比较。
原尺寸图为依据，裁剪放大与接触表只辅助定位。

| 检查项 | 局部验收标准 |
|---|---|
| 静止和冻结区域 | 0° 补偿归零；声明范围外点位不动；接缝对应一致，保全哈希不变 |
| 15° 下缘 | 不再出现相对源姿势新增的细长折痕、凹沟或轮廓凸点 |
| 30/45/60° | 保住已有横向锯齿改善；内侧/下缘没有非设计尖折或新裂缝，不靠另一处退化换改善 |
| 中间角度 | 先复核 0/5/10/15/20/30/45/60°；通过后做 0–60° 逐度扫描与回放，重点复核补偿启停附近及异常角度 |
| 几何连续与体积外观 | 检查边长变化、相邻面折角/法线变化与非相邻相交，并逐图看轮廓和体积；不以相交为零替代自然变形，不用未封闭选区的有符号体积冒充整体体积 |
| 实现可行性 | 同一姿势输入可重复产生同一形状；不能只保留几张静态目标而宣称已完成修复模型 |
| 扩展回归 | 右侧独立检查；原动作局部回归检查全部采样帧，记录实际采样率/视角；抽样只能用于提前发现失败，不能宣布完整通过 |

逐度诊断和原动作回归仅覆盖本计划声明的范围；
正式膝关节 0–120°、八方位及生产动作逐帧要求仍由 Rig v2 原合同控制。
任何可见非设计折痕仍在时，可以记录某项局部改善，但不能标记“左膝已修复”。

## 5. 尝试预算与切换条件

预算以可审查的实验版数控制，避免无限调整；不是成功时间承诺。

- P1：一轮定位；若仍不能区分主要原因，最多补一次针对缺口的诊断，再输出未决项。
- P2：最多两版有明确假设的局部形状试修。首版针对主要原因；只有能指出首版的具体缺口，才做第二版。
- P3 若因形状问题退回，仍计入这两版预算，不能通过更换阶段名重新开始计数；右侧执行时独立记录同样的局部尝试预算。
- 两版都不能同时改善 15° 和 60°，或只能把褶皱移到邻近区域：停止本轮形状补偿路线，整理证据进入 S 的方案选择。
- 任一版出现冻结区漂移、接缝破坏或既有改善退化：该版直接拒绝，不继续扩展。
- S：只执行证据最强的一种结构性办法，首版加最多一次有依据的修正。没有增益则结束该办法，交付失败位置及所需专业 DCC 工作，不能循环枚举参数。
- 局部通过后才投入 P3/P4 的完整回归；若实现可行性失败，停止扩展静态补偿效果。

条件分支 S 的选择依据：

| 证据 | 优先办法 |
|---|---|
| 明确存在不合理骨影响或梯度突变，并能解释目标面片挤压 | 针对已定位面片的权重修整；说明与 CHANGE-034 后侧统一降权有何区别 |
| 实际关节轴/中心与网格弯曲区不匹配，且诊断排除了单纯目标边界问题 | 隔离验证关节位置及其影响；不依据一个相交数字移动骨架 |
| 固定区域/合理权重仍无法形成压缩与展开，缺陷与局部布线组织对应 | 设计膝部定向布线/局部重拓扑；先核实接边、静止轮廓、UV 和权重迁移成本 |
| 原因仍不明确，或现有工具不能完成可控局部修形 | 输出已绑定的失败区域和交接材料，先解决诊断/制作能力缺口 |

目前没有证据要求整只角色重新生成或更换供应商。
局部方案失败只能否定该方案；是否需要更大范围重做要另列证据和成本，
不能把“这版失败”解释成“任何方法都不可能”。
