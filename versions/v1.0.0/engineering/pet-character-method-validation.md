## 1. 对路线的结论

已有局部修复确实减少过方向异常和自交，但当前三角底网不能只靠“两两合并成四边面”满足核心四价要求。本轮发现 **86 个必要条件失败的核心点**，并独立枚举验证其中一个固定导向点。因此停止对这份不变底网继续投入配对求解，也停止把四点边界提案当作通往合格关节网格的主要下一步。

这只排除了明确的一条路线：**保持本轮三角连接和顶点，只删配对公共边**。不同三角连接、新点集、先设计四边面流仍未被证明不可行。没有“整体无法修复”或“必须人类接手”的结论，也没有“现已掌握完整自动建模方法”的证据。

## 3. 配对失败的可复核依据

输入是 CHANGE-087 合并接缝身份后的真实审计网格：3,824 点、7,232 三角、160 固定四边面，SHA-256 `df8134d882f6d02b77eeb56b2cdd31c77a57c0cc594e4a364d0932b9b54be9a5`。

设某点当前有 d 条邻接边、t 个相邻三角、r 条可能删除的三角/三角公共边。达到四价需要删 d−4 条边；每条被删边消耗两个不同的相邻三角。因此必要条件为：

`0 ≤ d−4 ≤ min(floor(t/2), r)`。

这里乐观地允许所有三角/三角公共边，不先排除畸形配对，所以失败仍能排除仅配对路线；通过则**不证明有完整合格配对**。固定四边面及其边保持。

真实核心共 2,783 点；加上通过不可删除边连接的邻点，共 2,815 个必保护点。未将旧网格的整个一圈误当成最终实际一圈。86 个失败全部位于核心：度 3/7/8/9/10/12 分别为 11/7/1/50/16/1 个；其中九个为固定导向身份。

独立证据 `fixed:832`：7 条邻边、5 个相邻三角、2 个固定四边面。对四条可能删除的边穷举不重复使用三角的子集，最多只能删 2 条，最终至少 5 条邻边，无法达到 4。此枚举不调用新检查器。

CHANGE-090 四点提案只替换三处边界原面；其原顶点与全部 86 个失败点交集为空，新增源事件也在核心外。即便这三处局部表面成功，86 个内部障碍仍存在。因此四点提案保留为局部曲线方案，**不作为当前生产路线的优先施工项**。

## 4. 外部方案筛选结果

| 方案 | 已查依据 | 对本项目的处理 |
|---|---|---|
| Pattern-Based Quadrangulation | [作者项目](https://igl.ethz.ch/projects/patch-quad/)：先有分区和边数，再产生内部连接 | 借鉴“先定拓扑”的顺序。此前模板/调和布点失败路线不重开 |
| Directional 方向场 | [作者教程 §401 / §503 / §505](https://github.com/avaxman/Directional/blob/master/docs/tutorial.md)：可指定奇异点指标，整数化后提取面 | 值得进一步核查布局表达能力；只对接缝取整可能仅得 quad-dominant，全局指标和边界循环需处理。未实测固定坐标/160 面保持，不直接准入构造 |
| Topological IGM 初始化 | [Livesu 2023](https://doi.org/10.1016/j.cag.2023.03.005)及[原作者代码](https://github.com/mlivesu/topological_IGM) | 作者承认较大畸变和不足的连接质量。所读示例需 CinoLib / OpenGL，IGM overlay 在 genus>1 分支；不能直接拿来生成本项目五开口身体，排除为当前即用方案 |
| 粗四边分区 | [Viertel 等 2019](https://arxiv.org/abs/1905.09097) | 保留研究线索，未找到已核实能接入本项目冻结条件的执行方案 |
| Animation-Aware Quadrangulation | [作者项目](https://igl.ethz.ch/projects/animation-aware-quadrangulation/) | 需要有对应关系的变形序列；当前没有合格动作输入，不能解决眼前的静态身体缺口 |

UV、自动权重、USD 的工具能力分别核对了 Blender 4.3 官方 [Data Transfer](https://docs.blender.org/manual/en/4.3/modeling/modifiers/modify/data_transfer.html)、[Armature Parenting](https://docs.blender.org/manual/en/4.3/animation/armatures/skinning/parenting.html)、[USD](https://docs.blender.org/manual/en/4.3/files/import_export/usd.html)。它们支持后续步骤，但不会自动补齐当前缺失的身体面流。
